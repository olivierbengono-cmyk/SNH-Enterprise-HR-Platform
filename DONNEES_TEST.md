## Utilisation pour les tests

### Scénarios de test recommandés

1. **Test Employé**
   - Se connecter avec un compte employé
   - Consulter ses bulletins de paie
   - Faire une demande de congé
   - S'inscrire à une formation
   - Consulter son historique

2. **Test Manager**
   - Se connecter avec un compte manager
   - Voir la liste de son équipe
   - Valider/rejeter des demandes de congés
   - Consulter les performances de l'équipe
   - Faire des rapports

3. **Test DRH**
   - Se connecter avec le compte DRH
   - Vue d'ensemble des effectifs
   - Gérer les recrutements
   - Consulter les analytics RH
   - Gérer les formations
   - Exporter des rapports

## Notes importantes

⚠️ **Pour créer des comptes utilisateurs réels**:
Les employés doivent s'inscrire via l'interface de login en utilisant leur email professionnel (@snh.cm). Pour les tests, vous pouvez créer manuellement des comptes via Supabase Auth en utilisant les emails listés ci-dessus.

⚠️ **Données fictives**:
Toutes les données sont fictives et créées uniquement à des fins de démonstration. Les noms, adresses et numéros de téléphone sont générés pour la présentation.
