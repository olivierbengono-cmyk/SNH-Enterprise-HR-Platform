Récapitulatif des fonctionnalités
Fonctionnalités du module Recrutement
Vue synthétique de l'ensemble des fonctions couvertes par le portail candidat et l'interface d'administration RH.
🌐
Portail public bilingue
Page d'accueil publique présentant les offres SNH en temps réel. Interface disponible en français et en anglais, sans installation requise.
FR / EN Responsive Sans compte
📋
Profil candidat complet
Saisie structurée des informations personnelles (date de naissance obligatoire), formations, expériences, compétences, langues et liens professionnels.
Taux de complétion Photo profil Validation
📄
Génération de CV PDF
Deux templates professionnels (Classique SNH + Moderne), générant un PDF prêt à l'impression incluant le logo SNH, la photo et la date de naissance.
Template Classique Template Moderne Logo SNH
📬
Candidature & documents
Dépôt de candidature sur offre publiée ou spontanée (emploi, stage académique ≤ 2 mois, stage professionnel) avec pièces jointes vérifiées.
CDI / CDD Stage acad. ≤ 2 mois Lettre de motivation
🔔
Notifications automatiques
À chaque évolution du dossier (examen, entretien, offre, essai, titularisation, refus), le candidat reçoit une notification dans son espace en temps réel.
Trigger SQL Temps réel Historique
🗂
Pipeline de recrutement (RH)
Interface admin avec 6 étapes : Soumis → En examen → Entretien → Offre → Essai → Titularisé(e). Publication d'offres réservée aux rôles privilégiés.
6 étapes Rôles Brouillon → Publié
Stack technique
React + TypeScript Vite + Tailwind CSS Supabase (PostgreSQL + Auth) RLS & Triggers SQL Edge Functions (Deno) Génération PDF HTML
